WINDOWS X64 · 2026-10-11 · 基于 v0.7.0-beta.5 的本机定制版

都市回响：自由选择歌词位置

原文在上、译文在下，译文字号约为原文的 75%。保留整组倾斜和律动；六个区域可多选，每个区域可单独拖动、缩放。网易云时间自动同步，无需先估计提前或延后多少秒。

1 · 安装与启动

当前适配网易云音乐 3.1.40.205461 / 3.1.41.205529 x64，本机验证环境为 Windows 11 x64。其他客户端版本会提示未适配。无需安装 Python 或 Git。

  1. 将 ZIP 完整解压到长期保留且可写的目录，例如 D:\DancingLyrics-NetEase。保留 FloatingLyrics.exe 和整个 _internal，不要在压缩包内直接运行。
  2. 完全退出网易云，包括右下角托盘。双击 安装网易云联动.bat。
  3. 确认网易云安装目录（包含 cloudmusic.exe）。BetterNCM 数据目录默认 C:\betterncm，需使用英文路径。点击“安装”。首次缺少框架时会下载并校验官方 BetterNCM 1.3.4；如果提示权限不足，使用安装器提供的“以管理员身份重试”。
  4. 安装成功后重新打开网易云。播放栏点击“都市回响”开启效果；点击旁边“设置”或右键“都市回响”打开控制面板。

日常网易云联动从网易云播放栏开启。包内“启动.bat”用于打开本地音乐模式。暂停、切歌、音量继续在网易云操作。

2 · 多选位置，调整各自的范围

  1. 在设置的“歌词效果 → 显示与文字”中点击“选择六个位置与范围…”。
  2. 自由勾选左上、右上、左中、右中、左下、右下，至少选一个。只选左上和右上就会在顶部交替；选一个就一直使用该区域。
  3. 点击预览中的画框，拖动内部移动，拖右下角缩放。也可从下拉框选择区域，输入左边距、上边距、宽度、高度的百分比。每个框独立保存；屏幕指主屏可用区域，不含任务栏。
  4. 点击“保存并应用”，显示区域会自动切换成“自选位置与范围（可多选）”。取消不保存修改。

歌词依次按“左上 → 右上 → 左中 → 右中 → 左下 → 右下”的勾选顺序轮流出现，空白句不占次数。左侧区域靠左，右侧区域靠右，防止短句靠近屏幕中央。边界计算包含倾斜、发光与跳动的空间；缩放范围保留设置的字号，长句自动换行；框太小仍放不下时会跳过该句，请扩大范围。

想更贴边：左侧框左边距设为 2%，右侧框左边距设为 68%、宽度设为 30%；再按自己屏幕拖动微调。不要把边框拉进不想出现歌词的中央区域。

3 · 双语、倾斜与自动对齐

设置怎么选
歌词语言勾选“原文与中文翻译上下同时显示”。原文大、译文小；歌曲没有中文译文时只显示原文。
倾斜角度例如 15°，原文和译文一起倾斜；设成 0° 才是水平。
律动与同步开启“自动对齐网易云歌词时间”（默认开启），延迟保持 0 ms。暂停、拖动进度和切歌自动跟随网易云。

自动对齐使用网易云的播放时钟和歌词时间点，并补偿本机进度消息的传输间隔；新句在时间点直接可见，减少入场渐显带来的视觉滞后。倾斜、律动和退场动画仍保留。关闭自动对齐可恢复完整入场效果。此功能不读取原版桌面歌词窗口，原版客户端的渲染和歌词源差异仍可能带来少量误差；没有做逐帧零误差保证。

4 · 更新、故障与卸载

  • 旧版更新：完全退出网易云和歌词程序，保留 .state 文件夹，将新版文件覆盖到原目录，然后重新运行“安装网易云联动.bat”更新同步插件。只替换 EXE 不足以启用本次采样时间补偿。安装后移动目录也要重新安装联动。
  • 没有歌词：先确认歌曲本身有歌词、“都市回响”已启用、选择了至少一个区域；纯音乐保持空白。不要同时开两份歌词程序。
  • 没有翻译：译文取自网易云，不在线生成翻译；换一首自带中文翻译的歌曲检查。
  • 卸载：退出网易云，运行“卸载网易云联动.bat”。保留个人数据和共用框架。
